# Detailed scientific documentation

Use [the reproduction guide](../REPRODUCTION.md) for supported tasks and
[the results index](../RESULTS_INDEX.md) for current data paths.

- [Numerical methods](numerical_reproduction.txt): fixed random-call order,
  budgets, uncertainty definitions and independent-check coverage.
- [Biological methods and paths](biological_reproduction.txt): rules, targets,
  context selection, certificates, eligibility and reproduction locators.
- [Biological reference text](biological_extended_details.tex): detailed
  scientific qualifications, witnesses and bibliography in TeX notation.
- [Biological tables](biological_tables.tex): full small-model rule tables,
  source availability, environmental assignments, selected-target outcomes,
  resource measurements and the complete CD4 target table.

The TeX files are reference text, not standalone PDF builds. Their table labels
and descriptive section headings identify the material. Source/current hashes
and recorded commitments are explained in [repository integrity](../RELEASE.md).
